# Wayfinder design

Use the system font stack defined in `styles.css`. Reuse `--paper` (#f4f7f4), `--card` (#fff), `--ink` (#142b31), `--deep` (#102b35), `--blue` (#197b78) and semantic green/red states. Preserve compact Timeline and Route cards, tabular times, existing facility icons and accessible names on icon-only controls. Reuse safe-area padding, narrow single-column layout, visible keyboard focus and reduced-motion rules. Verify end labels, route input controls and leg-status text at narrow widths.
